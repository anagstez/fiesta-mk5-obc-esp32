# Сирі дампи CAN-кадрів

Текстові логи, записані [`tools/rec.py`](../tools/rec.py) / [`tools/guided.py`](../tools/guided.py) з USB-виходу
прошивки (команда `D`).

Формат рядка: `<секунди від початку> <шина> <ID hex> [dlc] <байти hex>`, шина `M` = MS-CAN, `H` = HS-CAN. Рядки `I (...)`
— лог прошивки, вони іноді вплітаються між кадрами (`tools/analyze.py` їх відкидає). Рядки `#LABEL …` — мітки керованого тесту.

**Дампи містять лише зміни** (дедуплікація на платі), тож це лог змін, а не повна стрічка кадрів. Див. §3 у
[`docs/CAN-ANALYSIS.md`](../docs/CAN-ANALYSIS.md).
